# ربط واتساب عشيش — V147

هذا الربط لا يحتاج خادمًا سحابيًا أو اشتراك API. يعمل كـ **جسر محلي على نفس الكمبيوتر** الذي يشغّل لوحة الإدارة، ويتم ربط الحساب مرة واحدة عبر QR مثل WhatsApp Web.

> ملاحظة مهمة: لا يمكن للمتصفح وحده إرسال رسائل واتساب تلقائيًا في الخلفية. لذلك يوجد برنامج محلي صغير يحافظ على جلسة واتساب. لا توجد بيانات واتساب على خادم خارجي من طرف هذا الجسر.

## التشغيل لأول مرة

1. ثبّت Node.js LTS.
2. افتح مجلد `whatsapp-local-bridge` في Terminal / CMD.
3. نفّذ:

```bash
npm install
npm start
```

4. افتح لوحة الإدارة.
5. ادخل إلى **الإعدادات** وستجد بطاقة **ربط واتساب بالـ QR**.
6. اضغط **بدء الربط / تحديث QR**.
7. من الهاتف: WhatsApp → الأجهزة المرتبطة → ربط جهاز، ثم امسح QR.
8. انتظر ظهور **متصل وجاهز**.
9. جرّب **إرسال اختبار**.

بعد الربط لا تحتاج إلى مسح QR كل مرة؛ جلسة `LocalAuth` تحفظ الربط على الجهاز. يجب إبقاء برنامج الجسر يعمل حتى تصل الإشعارات تلقائيًا.

## الإشعارات التلقائية

تم ربط الجسر مع `ASHISH_WA.send` الموجود في المشروع. لذلك إشعارات الطلبات الحالية التي يستدعيها الأدمن يمكن تمريرها للجسر المحلي أولًا. إذا لم يكن الجسر يعمل، يعود النظام إلى المسار القديم بدل توقف الموقع.

## الأمان

الجسر يستمع على `127.0.0.1` فقط، وليس على الإنترنت. لا تفتح المنفذ 3030 للعامة.

## فصل الجهاز

من بطاقة واتساب في الأدمن اضغط **فصل الجهاز**، ثم يمكن مسح QR لحساب آخر.
